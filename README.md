# Levenshtein Distance

Веб-сервис сравнивает два текстовых файла по расстоянию Левенштейна. Один и тот же эндпоинт обслуживает и браузер,
и API-клиентов — ответ зависит от заголовков запроса.

**Стек:** Node.js · TypeScript · Express · Handlebars · Multer · string-comparison

## Как это работает

| Запрос | Ответ |
| --- | --- |
| `GET /` с `Accept: text/html` | HTML-форма: текст запроса и два `.txt`-файла |
| `POST /` как `multipart/form-data` (форма) | файл «Ответ на запрос.txt» с результатом для скачивания |
| `POST /` с JSON `{ text, file1, file2 }`, файлы в base64 | результат в JSON |

Принимаются только текстовые файлы (`text/plain`); при пустом тексте или отсутствии файлов возвращаются ошибки
валидации — в форме или в JSON.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
```
